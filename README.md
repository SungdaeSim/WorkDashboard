# 팀 업무 배분 매트릭스 (Work Dashboard)

팀원별 · 과제별 업무 배분을 한눈에 확인하고 드래그 앤 드롭으로 관리할 수 있는 2차원 매트릭스 형태의 웹 애플리케이션입니다.

React, Babel, Tailwind CSS를 CDN으로 불러오는 **단일 HTML 파일**로 구현되어 있어 별도의 설치나 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열기만 하면 됩니다.

```
open index.html
```

## 주요 기능

- **매트릭스 레이아웃**: 세로축은 과제명, 가로축은 담당자로 구성된 스윔레인 형태의 매트릭스에서 업무 카드를 확인할 수 있습니다.
- **업무 추가/수정/삭제**: 상단 "+ 새 업무 추가" 버튼으로 업무명, 과제, 담당자, 상태, 기간(시작일~마감일)을 입력해 새 업무를 생성합니다. 업무 카드를 더블클릭하면 같은 모달이 수정 모드로 열려 내용을 바꾸거나 삭제할 수 있습니다.
- **상태 표시**: 업무는 대기(회색) · 진행중(주황) · 완료(초록) 상태를 가지며, 카드 왼쪽 색상 띠와 배지로 한눈에 구분됩니다.
- **지연 표시**: 완료 상태가 아닌 업무의 마감일이 지나면 카드 색상(테두리·배지·날짜)이 빨간색으로 바뀌어 즉시 눈에 띕니다.
- **드래그 앤 드롭**: HTML5 Native Drag and Drop API를 사용해 업무 카드를 다른 셀로 옮기면 해당 과제/담당자로 자동 재배정됩니다.
- **필터링**: 매트릭스 위 필터에서 과제 또는 담당자를 선택하면 해당 행/열만 표시됩니다. 우측 상단 상태 범례(대기/진행중/완료/지연)는 여러 개를 동시에 선택할 수 있는 다중 필터로, 클릭할 때마다 켜지고 꺼집니다(예: 진행중 + 지연 동시 선택). **완료 상태는 기본적으로 숨겨져 있으며**, "완료" 배지를 클릭하면 다시 볼 수 있습니다.
- **담당자 관리**: 매트릭스 헤더에서 담당자를 추가/이름 변경/삭제할 수 있습니다. 담당자를 삭제하면 그 담당자의 업무는 "담당자 미지정" 열로 자동 이동합니다. 담당자 열은 이름 가나다순으로 자동 정렬됩니다(순서를 임의로 바꿀 수는 없습니다).
- **담당자 미지정 열**: 담당자가 지정되지 않은 업무를 위한 전용 열이 항상 제공되며, 이 열로도 카드를 드래그하거나 업무 추가 시 직접 선택할 수 있습니다.
- **과제 관리**: 각 행 헤더에서 과제명을 실시간으로 수정하고, 하단 입력창으로 새 과제를 추가하고, `⠿` 손잡이를 드래그하여 순서를 바꾸고, ✕ 버튼으로 삭제(속한 업무도 함께 삭제)할 수 있습니다.
- **편집 잠금**: 담당자/과제를 추가·수정·삭제하려면 우상단 "🔒 편집 잠금 해제" 버튼으로 비밀번호를 입력해야 합니다. 기본 비밀번호는 `index.html`의 `EDIT_PASSWORD` 상수(기본값 `1234`)이며, 배포 전 반드시 변경하세요. 클라이언트 코드에 그대로 노출되는 값이라 실수로 인한 편집을 막는 용도이며 실제 보안 장치는 아닙니다.
- **로컬 저장**: 별도 서버 없이 브라우저의 `localStorage`에 데이터가 자동 저장되어, 새로고침해도 입력한 내용이 유지됩니다.

## 초기 세팅 데이터

- 팀원: 김철수, 이영희, 박민수
- 과제: 자율주행 모빌리티 엑스포, 커넥티드 카 서비스 기획, 팀 공통(총무)

## 기술 스택

- [React 18](https://react.dev/) (CDN, UMD 빌드)
- [Babel Standalone](https://babeljs.io/docs/babel-standalone) (브라우저에서 JSX 변환)
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
