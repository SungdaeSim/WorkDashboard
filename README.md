# 팀 업무 배분 매트릭스 (Work Dashboard)

팀원별 · 과제별 업무 배분을 한눈에 확인하고 드래그 앤 드롭으로 관리할 수 있는 2차원 매트릭스 형태의 웹 애플리케이션입니다.

React, Babel, Tailwind CSS를 CDN으로 불러오는 **단일 HTML 파일**로 구현되어 있어 별도의 설치나 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열기만 하면 됩니다.

```
open index.html
```

## 주요 기능

- **매트릭스 레이아웃**: 세로축은 과제명, 가로축은 담당자로 구성된 스윔레인 형태의 매트릭스에서 업무 카드를 확인할 수 있습니다.
- **업무 추가**: 상단 "+ 새 업무 추가" 버튼으로 모달을 열어 업무명, 과제, 담당자, 기간(시작일~마감일)을 입력해 새 업무를 생성합니다.
- **드래그 앤 드롭**: HTML5 Native Drag and Drop API를 사용해 업무 카드를 다른 셀로 옮기면 해당 과제/담당자로 자동 재배정됩니다.
- **담당자 관리**: 매트릭스 헤더에서 담당자를 추가하거나(이름 입력 후 "추가") 삭제(✕ 버튼)할 수 있습니다. 담당자를 삭제하면 그 담당자의 업무는 "담당자 미지정" 열로 자동 이동합니다.
- **담당자 미지정 열**: 담당자가 지정되지 않은 업무를 위한 전용 열이 항상 제공되며, 이 열로도 카드를 드래그하거나 업무 추가 시 직접 선택할 수 있습니다.
- **로컬 저장**: 별도 서버 없이 브라우저의 `localStorage`에 데이터가 자동 저장되어, 새로고침해도 입력한 내용이 유지됩니다.

## 초기 세팅 데이터

- 팀원: 김철수, 이영희, 박민수
- 과제: 자율주행 모빌리티 엑스포, 커넥티드 카 서비스 기획, 팀 공통(총무)

## 기술 스택

- [React 18](https://react.dev/) (CDN, UMD 빌드)
- [Babel Standalone](https://babeljs.io/docs/babel-standalone) (브라우저에서 JSX 변환)
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
