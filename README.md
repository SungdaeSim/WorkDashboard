# 팀 업무 배분 매트릭스 (Work Dashboard)

팀원별 · 과제별 업무 배분을 한눈에 확인하고 드래그 앤 드롭으로 관리할 수 있는 2차원 매트릭스 형태의 웹 애플리케이션입니다.

React, Babel, Tailwind CSS를 별도의 설치나 빌드 과정 없이 그대로 사용하는 순수 HTML/JS 앱입니다. 인터넷 연결 없는 오프라인 PC에서도 쓸 수 있도록, 필요한 라이브러리 파일을 CDN이 아니라 저장소 안의 `vendor/` 폴더에 직접 포함해뒀습니다.

## 실행 방법

`index.html`과 `vendor/` 폴더를 **같은 위치에 함께 둔 채로** `index.html` 파일을 브라우저로 열면 됩니다. 인터넷 연결이 없어도 동작합니다.

```
open index.html
```

`vendor/` 폴더 안의 파일:

| 파일 | 라이브러리 |
| --- | --- |
| `react.development.js` | React 18 |
| `react-dom.development.js` | React DOM 18 |
| `babel.min.js` | Babel Standalone (브라우저 JSX 변환) |
| `tailwindcss-browser.js` | Tailwind CSS (`@tailwindcss/browser`, 브라우저 런타임) |

이 파일들은 `index.html`이 참조하는 정확한 버전이므로 임의로 교체하지 마세요. 업데이트가 필요하면 인터넷이 되는 PC에서 아래 명령으로 새로 받아 교체할 수 있습니다.

```
npm pack react@18 react-dom@18 @babel/standalone @tailwindcss/browser
```
받은 tgz 파일들을 풀어서 각각 `umd/react.development.js`, `umd/react-dom.development.js`, `babel.min.js`, `dist/index.global.js`를 `vendor/` 안의 같은 이름 파일로 교체하면 됩니다.

## 주요 기능

- **매트릭스 레이아웃**: 세로축은 과제명, 가로축은 담당자로 구성된 스윔레인 형태의 매트릭스에서 업무 카드를 확인할 수 있습니다. 화면 너비를 최대한 활용하도록 폭 제한 없이 브라우저 전체 너비에 맞춰 확장됩니다.
- **업무 추가/수정/삭제**: 상단 "+ 새 업무 추가" 버튼으로 업무명, 과제, 담당자, 상태, 기간(시작일~마감일)을 입력해 새 업무를 생성합니다. 업무 카드를 더블클릭하면 같은 모달이 수정 모드로 열려 내용을 바꾸거나 삭제할 수 있습니다. 매트릭스의 빈 셀을 더블클릭해도 그 과제·담당자가 미리 채워진 상태로 새 업무 추가 모달이 열립니다.
- **행/열 강조**: 매트릭스 위에서 마우스를 움직이면 커서가 있는 셀의 과제(행)와 담당자(열)가 옅게 강조되어, 지금 어느 과제·담당자 칸을 보고 있는지 한눈에 알 수 있습니다.
- **상태 표시**: 업무는 대기(회색) · 진행중(주황) · 완료(초록) 상태를 가지며, 카드 왼쪽 색상 띠와 배지로 한눈에 구분됩니다.
- **지연 표시**: 완료 상태가 아닌 업무의 마감일이 지나면 카드 색상(테두리·배지·날짜)이 빨간색으로 바뀌어 즉시 눈에 띕니다.
- **드래그 앤 드롭**: HTML5 Native Drag and Drop API를 사용해 업무 카드를 다른 셀로 옮기면 해당 과제/담당자로 자동 재배정됩니다. **Shift 또는 Ctrl 키를 누른 채 드래그**하면 카드를 이동시키지 않고 복사본을 만들어 놓습니다(놓는 순간까지 키를 누르고 있어야 함) — 드롭 대상 셀이 이동 시 파란색, 복사 시 초록색으로 표시되어 구분됩니다.
- **필터링**: 매트릭스 위 필터에서 과제 또는 담당자를 선택하면 해당 행/열만 표시됩니다. 우측 상단 상태 범례(대기/진행중/완료/지연)는 여러 개를 동시에 선택할 수 있는 다중 필터로, 클릭할 때마다 켜지고 꺼집니다(예: 진행중 + 지연 동시 선택). **완료 상태는 기본적으로 숨겨져 있으며**, "완료" 배지를 클릭하면 다시 볼 수 있습니다.
- **담당자 관리**: 매트릭스 헤더에서 담당자를 추가/이름 변경/삭제할 수 있습니다. 담당자를 삭제하면 그 담당자의 업무는 "담당자 미지정" 열로 자동 이동합니다. 담당자 열은 이름 가나다순으로 자동 정렬됩니다(순서를 임의로 바꿀 수는 없습니다).
- **담당자 미지정 열**: 담당자가 지정되지 않은 업무를 위한 전용 열이 항상 제공되며, 이 열로도 카드를 드래그하거나 업무 추가 시 직접 선택할 수 있습니다.
- **과제 관리**: 각 행 헤더에서 과제명을 실시간으로 수정하고, 하단 입력창으로 새 과제를 추가하고, ✕ 버튼으로 삭제(속한 업무도 함께 삭제)할 수 있습니다. `⠿` 손잡이를 드래그해 순서를 바꾸는 것은 편집 잠금 여부와 관계없이 항상 가능합니다. 드래그하는 동안 해당 행이 커서를 따라다니듯 표시되고(반투명 처리), 다른 행 위로 지나가면 그 행들이 즉시 자리를 비켜주며 순서가 바뀝니다.
- **편집 잠금**: 담당자/과제를 추가·이름 변경·삭제하려면(순서 변경은 예외) 우상단 "🔒 편집 잠금 해제" 버튼으로 비밀번호를 입력해야 합니다. 기본 비밀번호는 `index.html`의 `EDIT_PASSWORD` 상수(기본값 `1234`)이며, 배포 전 반드시 변경하세요. 클라이언트 코드에 그대로 노출되는 값이라 실수로 인한 편집을 막는 용도이며 실제 보안 장치는 아닙니다.
- **저장 / 불러오기**: 우상단 "불러오기"로 JSON 파일을 열고 "저장"으로 다시 저장합니다(편집 잠금 여부와 무관하게 항상 가능). 이 방식으로 여러 PC/브라우저 간에 데이터를 옮길 수 있습니다. 불러온(또는 마지막으로 저장한) 파일 이름은 제목 옆에 작게 표시됩니다.
  - **Chrome / Edge**: File System Access API를 사용해, 불러온 파일을 "저장"할 때 원래 파일 위치에 실제로 덮어씁니다. 덮어쓰기 전 확인창이 뜨고, "취소"를 누르면 다른 이름/위치로 저장할 수 있는 대화상자가 대신 열립니다. 불러오기 없이 새로 만든 데이터를 처음 저장할 때도 이 대화상자로 위치와 이름을 지정합니다. "불러오기"/"저장" 대화상자는 마지막으로 열거나 저장한 파일의 폴더를 기억해뒀다가 다음에도 그 폴더에서 시작합니다(브라우저를 껐다 켜도 유지). 단, **이 브라우저에서 이 앱으로 파일을 한 번도 연 적이 없는 최초 1회**는 `index.html`이 있는 폴더를 자동으로 알아낼 방법이 없어(브라우저 보안 정책상 웹페이지가 자기 파일의 위치를 알 수 없음) 사용자가 직접 그 폴더까지 이동해 한 번 선택해야 합니다. 그 이후로는 자동으로 그 폴더에서 시작합니다.
  - **Firefox / Safari 등**: 이 API를 지원하지 않아 원본 파일에 직접 덮어쓸 수 없으므로, 대신 브라우저 다운로드로 저장합니다. 이미 파일 이름이 있으면 그 이름으로 바로 다운로드하고, 새로 만든 데이터는 처음 저장할 때만 파일 이름을 물어봅니다. 다운로드된 파일이 원본과 같은 폴더에 저장되는지는 브라우저의 다운로드 설정에 따라 다릅니다.
- **브라우저 저장 없음**: 데이터는 `localStorage` 등에 자동 저장되지 않습니다. 새로고침하거나 다시 열면 항상 빈 매트릭스로 시작하며, JSON 파일을 다시 "불러오기" 해야만 내용이 보입니다. 파일을 불러오지 않은 채로 예전에 남아 있던 브라우저 데이터를 보여주면 그게 최신인지 알 수 없기 때문에, 매번 명시적으로 불러오도록 한 것입니다.
- **파일 형식에 관대함**: 불러오는 JSON 파일에 일부 필드가 없거나 형식이 바뀌어도 에러 없이 빈 값으로 채워 불러옵니다. 향후 앱에 새 필드가 추가되거나 옛날 파일을 불러오는 경우에도 항상 열리도록 설계했습니다(JSON 구문 자체가 깨진 경우만 오류로 처리).

## 시작 화면

`index.html`을 열 때마다(처음이든 새로고침이든) 매트릭스는 항상 완전히 빈 상태로 시작합니다 — 이전에 불러왔던 데이터는 자동으로 다시 나타나지 않습니다. "불러오기"로 저장된 JSON 파일을 다시 불러오거나(잠금 여부와 무관), 편집 잠금을 해제한 뒤 담당자/과제를 직접 추가해 사용하세요.

## 기술 스택

- [React 18](https://react.dev/) (UMD 빌드, `vendor/`에 로컬 포함)
- [Babel Standalone](https://babeljs.io/docs/babel-standalone) (브라우저에서 JSX 변환, `vendor/`에 로컬 포함)
- [Tailwind CSS](https://tailwindcss.com/) (`@tailwindcss/browser` 런타임, `vendor/`에 로컬 포함)
